# QA магазина «Лавка»

Playwright и TypeScript для магазина из [тестового задания](https://qa-test.g-profile.ru/).

## Проверка задания

| Что открыть | Что там проверить |
| --- | --- |
| [Публичная витрина](https://lavka-qa-slavques.onrender.com/) | В исходном каталоге 16 товаров. Для регистрации и заказа используйте вымышленные данные. |
| [Публичная Grafana](https://lavka-monitoring-slavques.onrender.com/public-dashboards/8451f62756b3c4e40274741271c86b14) | Дашборд открывается без входа. Панель «Сбор метрик» показывает, отвечает ли магазин на сбор Prometheus. |
| [Запуск тестов](#запуск-автотестов) · [Матрица покрытия](docs/coverage.md) | Локальные команды, шесть областей ТЗ и пять HTTP-контрактов. |
| [26 баг-репортов](docs/bugs.md) | Приоритеты, шаги, ожидаемые и фактические результаты, скриншоты. |

Актуальный набор тестов проверен локально из чистого клона. Playwright выполнил 168 проверок, включая 75 ожидаемых воспроизведений известных дефектов. [Результат локального прогона](docs/coverage.md#контрольный-прогон)

После простоя Render Free первый ответ может занять около минуты. Перезапуск сбрасывает тестовые заказы и историю метрик. [Ограничения Render Free](https://render.com/docs/free)

## Запуск автотестов

Нужны Node.js 22+ и npm. Распакуйте [архив магазина](https://qa-test.g-profile.ru/download/qa-shop.zip) рядом с репозиторием.

```bash
git clone https://github.com/slavques/qa-shop-playwright.git
cd qa-shop-playwright
export SHOP_DIR="$PWD/../qa-shop"
npm ci
npm ci --prefix "$SHOP_DIR"
npx playwright install chromium firefox webkit
npm run typecheck
PLAYWRIGHT_FULL_MATRIX=1 npx playwright test
npm run report
```

Если архив распакован в другом каталоге, укажите путь к папке с `server.js` в `SHOP_DIR` перед установкой зависимостей. На Linux вместо команды установки браузеров используйте `npx playwright install --with-deps chromium firefox webkit`. Если порт `3100` занят, задайте `SHOP_PORT`.

Полная матрица включает Chromium, Firefox, WebKit, эмуляцию Pixel 7 и iPhone 13 и отдельные HTTP-контракты. Быстрые варианты — `npm test` для Chromium и `npm run test:api` для API. Для проверки стабильности добавьте `--repeat-each=2` к полному прогону. Автоматические ретраи отключены.

```bash
BASE_URL=https://lavka-qa-slavques.onrender.com npx playwright test
```

Команда с `BASE_URL` запускает только публичный smoke без записи данных. Последний успешный GitHub Actions относится к коммиту `827afd6`. [История CI](https://github.com/slavques/qa-shop-playwright/actions/workflows/playwright.yml)
